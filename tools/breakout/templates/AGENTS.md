## Finding knowledge — don't load everything

Docs are atomic and indexed. Do **not** read whole directories.

```sh
uv run --project tools {{tool}} docs search <terms> [--tag t]   # ranked hits with summaries
```

Then read only the hits. `docs/INDEX.md` lists every doc with a one-line summary.

## Rules

- **English** for code, identifiers, docs, commits.
- **Truncate long shell output** to save tokens: pipe through `head`/`tail`, `grep`, `wc -l`,
  `--stat`, `cut -c1-160` or quiet flags; read full output only when the truncated part matters.
- **Docs**: follow [docs/README.md](docs/README.md) — frontmatter, ≤150 lines, one topic per file,
  cite sources under `docs/knowledge/`. Run `{{tool}} docs index` after adding/renaming docs.
- **Events are facts**: past tense, never mutated, never deleted. Corrections are new events.
- **Rust**: `cargo fmt`, `cargo clippy --all-targets -- -D warnings`, `cargo test` must pass.
- **Python tools**: `uv run --project tools pytest` and `ruff check` must pass.
- No secrets in git. `infra/eventsourcingdb/.env` is local only.

## Known traps

Verify against the pins before relying on them; details in `docs/upstream-feedback/`.

- **EventSourcingDB docs may describe an unreleased version** (`preview`). Verify every
  documented feature against the pinned image.
- **architecturekit is 0.x with frequent breaking releases** — pinned exactly; an upgrade is its
  own commit plus an entry in `docs/upstream-feedback/upgrade-log.md` ([ADR-0005](docs/adr/0005-exact-version-pins-with-deliberate-upgrades.md)).
  It writes no actor/reason metadata — embed it in event payloads if you need it.
  Its `Schema` derive rejects enums, `tag`/`flatten`/`with` — use plain structs in event payloads.
- **ESDB numbers are f64** — integers > 2^53 as strings. Events ≤ 64 KiB: large payloads go to a
  blob store, events carry reference + hash.
- **ESDM**: `model/schemas/` must stay byte-identical to the binary (lint aborts on drift);
  upgrade only via `{{tool}} esdm update-schema`. The website lags the schema — the schema wins.

## Definition of done

1. `uv run --project tools {{tool}} check` passes.
2. Rust/Python checks pass for touched code.
3. Domain changes are reflected in `model/` and `{{tool}} esdm lint` is clean.
4. Decisions are captured as ADRs; open points as `docs/discussions/`.
5. Tool friction you hit is logged in `docs/upstream-feedback/`.
